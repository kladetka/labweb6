# Лабораторна робота №6 — відповіді на контрольні питання

1. **opacity / visibility / display.** `opacity: 0` — елемент прозорий, місце зберігається, з ним **можна** взаємодіяти (кліки, фокус). `visibility: hidden` — елемент невидимий, місце зберігається, взаємодіяти **не можна** (фокус не отримує). `display: none` — елемент прибирається з потоку, місця не займає, взаємодії немає.
2. **position:** `static` (за замовчуванням), `relative`, `absolute`, `fixed`, `sticky`. `static` і `relative` залишаються в потоці; `absolute` і `fixed` виймаються з потоку; `sticky` — гібрид `static` та `fixed`.
3. **relative** зсуває елемент відносно його початкового місця (місце в потоці зберігається). Якщо задати одночасно `left` і `right`, браузер віддає перевагу `left` (так само `top` над `bottom`).
4. `absolute` позиціонується відносно найближчого предка з `position`, відмінним від `static`. Без такого предка — відносно вікна (початкового блоку документа).
5. `fixed` прив'язаний до вікна браузера й не прокручується; `absolute` — до батька. Використовують для шапок, бокових меню, кнопок «вгору», модальних вікон.
6. `sticky` потребує `top` або `bottom`. Елемент поводиться як `static`, доки його межа не досягне вказаної відстані від краю вікна, тоді «прилипає» і відпускається, коли впреться в кінець батьківського елемента.
7. `z-index` працює для `relative`, `absolute`, `fixed` (і `sticky`). За замовчуванням — `auto`/`0`. При однакових значеннях зверху той елемент, що йде пізніше в коді.
8. **Псевдоклас** — ключове слово після селектора (`селектор:псевдоклас`), що вказує на стан або положення елемента. Звичайний клас задається атрибутом `class` у HTML, псевдоклас — ні, він визначається браузером.
9. `:hover` — курсор над елементом; `:active` — у момент натискання; `:focus` — елемент у фокусі (клік, Tab); `:visited` — відвідане посилання. Найчастіше для `a`, `button`, `input`.
10. **LVHA:** `:link` → `:visited` → `:hover` → `:active`. Через однакову специфічність виграє пізніше правило; при порушенні порядку одні стани перекриватимуть інші (наприклад, `:hover` не спрацює на відвіданому посиланні).
11. `:first-child` — перший, `:last-child` — останній, `:nth-child(n)` — за номером. Нумерація з 1.
12. `odd` — 1, 3, 5…; `even` — 2, 4, 6…; `3n+3` — 3, 6, 9, 12…
13. **Псевдоелемент** створює/вибирає частину елемента (`::before`, `::after`, `::first-line`, `::first-letter`). У CSS3 записується з подвійною двокрапкою, псевдокласи — з однією (одинарна для псевдоелементів теж підтримується з міркувань сумісності).
14. Без `content` псевдоелемент не генерується. Для `<input>`, `<img>` (замінюваних елементів) вмісту всередині немає, тому `:before`/`:after` до них не застосовуються.
15. `tabindex="0"` — елемент у природному порядку табуляції; `-1` — фокусується програмно/кліком, але не Tab-ом; додатні — змінюють порядок (не рекомендовано). У попапі `tabindex` робить кнопки й контейнер досяжними з клавіатури, а `visibility: hidden` на закритому попапі виключає його вміст з Tab.
